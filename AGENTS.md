# AGENTS.md

## Навигация

- `src/topsbottg/` – Python-приложение: Telegram-бот, API, бизнес-логика, модели и фоновые задачи.
- `frontend/` – интерфейс Mini App (HTML, CSS, JavaScript).
- `migrations/versions/` – миграции Alembic.
- `tests/` – автоматические тесты.
- `README.md`, `pyproject.toml`, `docker-compose.yml` – запуск, зависимости и конфигурация.

## Изменения кода

- Перед изменением изучи затрагиваемые файлы и связанные вызовы. Для локальной правки не требуется аудит всего репозитория.
- Решай поставленную задачу минимальными согласованными изменениями. Не добавляй несвязанный рефакторинг и зависимости без необходимости.
- Сохраняй обратную совместимость и существующие данные, если задача прямо не требует иного.
- При изменении контракта обновляй все затронутые уровни, вызовы и тесты.
- Следуй принятым в проекте соглашениям. Не заменяй существующий стек без обоснованной необходимости.
- Обрабатывай ошибки на подходящем уровне. Не скрывай сбои пустыми `except`, необоснованными подавлениями проверок или фиктивным успешным результатом.
- Для изменений схемы БД добавляй новую миграцию Alembic; не переписывай уже применённые миграции. Учитывай различия SQLite и PostgreSQL.
- Не раскрывай и не добавляй в код, логи или коммиты токены, пароли, приватные ключи и реальные персональные данные.
- Не выполняй деплой, `git push`, опасные операции Git, удаление данных или изменение работающих сервисов без явного запроса.

## Проверка

- Добавляй регрессионные тесты для изменённого поведения. При падении старого теста выясни, неверна реализация или устарело ожидание; не подгоняй тесты ради результата.
- Запускай относящиеся к задаче тесты; перед завершением по возможности выполняй полный набор:

```bash
python -m pytest -q
ruff check .
git diff --check
```

- Для изменённых JavaScript-файлов проверяй синтаксис через `node --check <file>`; при изменении интерфейса проверяй его поведение в браузере, если доступен.
- Не считай успешную проверку синтаксиса заменой тестов. Если проверка недоступна, укажи это явно.

## Результат

- Отвечай по-русски, кратко.
- Укажи, что изменено, какие проверки выполнены и что осталось непроверенным.
- Не утверждай, что исправление работает, если это не подтверждено соответствующей проверкой.
